# Product

Дата проекта: **05.11.2026**.

<!-- impeccable:product-schema 1 -->

## Platform
web, русский интерфейс; поддержка desktop и mobile.

## Users
Администратор регулярно ищет сотрудников, создаёт и редактирует учётные записи. Пользователь подтвердил сценарий рабочего реестра; ролевая модель в ТЗ отсутствует, CRUD доступен каждому вошедшему сотруднику.

## Product Purpose
Портал сотрудников Lasmart: вход по email/паролю, таблица ФИО и email, создание/редактирование в модальном окне, удаление с подтверждением. Список поддерживает поиск по подстроке ФИО без учёта регистра, сортировку по одному полю (ФИО по умолчанию), страницы 25/50/100.

## Capabilities and constraints
Angular/PrimeNG 21, ASP.NET 10, ADO.NET без ORM, PostgreSQL. Запуск через Docker Compose. Начальная учётка из env; пароли SHA-256 → bcrypt. Пустой пароль при редактировании сохраняет прежний, email изменяемый. Ошибки выделяют поля и сопровождаются сообщением.

## Brand commitments
Подтверждено: текущий шаблонный вид отвергнут. Убрать декоративные скруглённые карточки и градиенты. Новый дизайн должен служить удобному рабочему реестру. Официальные графические активы и фирменные цвета не предоставлены.

## Delivery
Локальный проект, журнал агентской разработки, независимый QA и ревью. Публикация GitHub отложена пользователем до указания репозитория.
