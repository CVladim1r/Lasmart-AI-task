# Журнал разработки

Дата: **05.11.2026**.

## Согласованные решения

- Вход по email сотрудника. Начальная учётная запись создаётся один раз из переменных окружения.
- Стек: Angular 21, PrimeNG 21, ASP.NET Core 10, PostgreSQL 17, ADO.NET без ORM. Запуск через Docker Compose.
- Пароли: SHA-256 → Base64 → bcrypt.
- Email можно менять; пустой новый пароль сохраняет существующий. Перед удалением требуется подтверждение.
- Интерфейс — компактный рабочий реестр без декоративных карточек, скруглений и градиентов. Публикация отложена до указания репозитория.

## Реализация

- Разработчик создал клиент, API, сервисный слой и DAL с параметризованными SQL-запросами.
- Реализованы вход, восстановление и завершение сеанса, CRUD сотрудников, валидация и уникальность email без учёта регистра.
- Добавлены cookie-аутентификация, CSRF-проверки и проверка существования сотрудника при восстановлении сеанса.
- Созданы схема БД, однократная инициализация начальной учётки, контейнеры и CI для сборки и проверок.
- Ведущий агент интегрировал дизайн: таблица, поиск по ФИО, сортировка по ФИО/email и страницы по 25, 50 или 100 строк.

## Тестирование и ревью

- Тестировщик проверил API, пользовательские сценарии и адаптивность. Независимое визуальное ревью завершено.
- Ведущий агент исправил замечания по передаче подтверждения пароля, CSRF-заголовкам, обработке ошибок, начальному пользователю и пагинации после удаления.
- Итоговые результаты: 14 компонентных тестов, 24 проверки API и 43 браузерные проверки прошли. Сборки клиента и API успешны.
- Результаты собраны в `QA_REPORT.md`, замечания и исправления — в `REVIEW.md`. Приложение оставлено доступным на `http://localhost:8080`.
