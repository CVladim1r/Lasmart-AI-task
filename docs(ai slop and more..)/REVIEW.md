# Ревью реализации

Дата: **05.11.2026**.

Ведущий агент проверил соответствие ТЗ, путь UI → API → сервис → DAL → PostgreSQL, валидацию, сеансы и контейнерный запуск. Замечания исправлены и проверены. Независимое визуальное ревью завершено.

## Исправленные замечания

| Проблема | Исправление |
| --- | --- |
| Клиент не передавал confirmPassword | Передаётся полный DTO |
| null-пароль и слишком длинное отчество вызывали ошибку | Null-safe валидация и серверные ограничения длины |
| Ошибки полей и удаления не обрабатывались полностью | Подсветка полей, доступные описания и уведомления ошибок |
| Сеанс удалённого сотрудника оставался действительным | Проверка существования сотрудника в OnValidatePrincipal |
| Seed восстанавливал изменённую или удалённую начальную учётку | Однократный bootstrap с маркером в транзакции |
| Отсутствовал обязательный CSRF-заголовок | Общие mutationOptions и регрессионные HTTP-тесты |
| После удаления последняя страница оставалась пустой | Ограничение номера страницы последней доступной |
| Не было сортировки по email | Выбор одного поля ФИО/email |
| PrimeNG 22 показывал лицензионное уведомление | Согласованный переход на Angular/PrimeNG 21 |

## Проверенные границы

- DAL использует SQL-параметры; идентификаторы маршрутов имеют тип UUID.
- Пароль и хеш отсутствуют в API-модели сотрудника и не подставляются в редактор.
- Пользовательский ввод и сообщения отображаются экранируемой интерполяцией Angular.
- CRUD защищён cookie-аутентификацией; изменяющие запросы требуют доверенный Origin и X-Requested-With.
- Полный UTF-8 пароль обрабатывается SHA-256 перед bcrypt с индивидуальной солью и work factor 12. Формат хеша версионирован.
- Данные сотрудников хранятся в атомарных полях; ФИО вычисляется. Начальная инициализация отделена от данных сотрудника.
