# Frontend

Дата проекта: **05.11.2026**.

Angular 21 + PrimeNG 21 интерфейс портала сотрудников. Основная документация запуска, API и архитектуры — в [README проекта](../README.md).

Команды из этой директории:

- `npm ci` — установить зафиксированные зависимости.
- `npm start` — запустить Angular dev server на `http://localhost:4200` с proxy `/api` к локальному API `http://localhost:5000`.
- `npm run build` — production build.
- `npm test -- --watch=false` — запустить unit/component tests однократно.
